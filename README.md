# PappaDrone
First Pappa Drone 

## Goal
Track the process of building a drone from scratch and document it here.

## Process
I have no experience with building drones, so I'm starting from scratch. I'll be using open source software and hardware as much as possible. 

The ultimate goal is to create an FPV drone that can be controlled by an RC controller and a set of FPV goggles such as the Meta Quest.

The drone should be able to fly autonomously and be controlled manually.

The drone shall also have VTOL capabilities, meaning it can take off and land vertically.

## Materials

- Flight controller: Ardupilot
- RC controller: OpenTX
- FPV goggles: Meta Quest
- Frame: 3d Printed
- Motors: 4 brushless motors
- ESCs: 4 Electronic Speed Controllers
- Camera: FPV camera
- Video transmitter: Video transmitter
- Battery: LiPo battery
- Propellers: 4 propellers
